# ShopApp

Консольна Java-програма для оформлення замовлення в інтернет-магазині. Користувач вводить дані про товар — назву, опис, категорію, кількість, ціну за одиницю та розмір знижки — а програма рахує суму без знижки, розмір знижки та підсумкову суму до сплати.

## Вимоги

Встановлений JDK (можна перевірити командою `java -version`).

## Компіляція та запуск

Відкрий термінал у папці з файлом `ShopApp.java` і виконай:

```
javac ShopApp.java
java ShopApp
```

Перша команда компілює файл (створює `ShopApp.class`), друга — запускає програму.

## Кирилиця в Windows

Якщо після запуску текст відображається кракозябрами, перед `java ShopApp` виконай:

```
chcp 65001
```

Це перемикає кодування консолі на UTF-8. Якщо не допомогло — зміни шрифт вікна cmd на Consolas або Lucida Console (Властивості → Шрифт).
