# ShopApp — Інтернет-магазин (консольний додаток)

Консольна Java-програма для оформлення замовлення в інтернет-магазині: користувач вводить дані про товар (назва, опис, категорія, кількість, ціна, знижка), а програма розраховує підсумкову суму до сплати.

## Можливості

- Введення назви, опису та категорії товару
- Введення кількості та ціни за одиницю
- Розрахунок знижки у відсотках
- Виведення підсумкового чека із сумою до сплати
- Коректна робота з кирилицею (UTF-8)

## Вимоги

- Встановлений **JDK** (Java Development Kit), версія 8 або новіша

Перевірити наявність Java:
```
javac -version
java -version
```

## Компіляція та запуск

1. Відкрий термінал (cmd / PowerShell / bash) у папці з файлом `ShopApp.java`.

2. Скомпілюй файл:
   ```
   javac ShopApp.java
   ```

3. Запусти програму:
   ```
   java ShopApp
   ```

### Проблеми з кирилицею у Windows

Якщо текст виводиться кракозябрами, перед запуском виконай:
```
chcp 65001
java ShopApp
```

Якщо не допомогло — зміни шрифт консолі на **Consolas** або **Lucida Console**:
Властивості вікна cmd → вкладка "Шрифт" → вибрати потрібний шрифт.
